### Entri 1: apa (1)

**Pemenggalan:** a.pa

#### Makna
1. **Pronomina (pron)**
   - kata tanya untuk menanyakan nama (jenis, sifat) sesuatu
   - **Contoh:** ular -- ini?
   - **Contoh:** pohon -- yang kautanam?
2. **Pronomina (pron)**
   - kata tanya untuk pengganti sesuatu
   - **Contoh:** -- yang dimaksudkan orang itu tadi?
3. **Pronomina (pron)**
   - kata tanya untuk menanyakan pertalian kekeluargaan
   - **Contoh:** (pernah) --mu anak itu?
4. **Pronomina (pron)**
   - pengganti sesuatu yang kurang terang
   - pengganti barang sesuatu
   - **Contoh:** ia tidak tahu -- isi kotak itu
5. **Partikel (p); Hormat (hor)**
   - untuk menghaluskan permintaan
   - **Contoh:** sudi --lah kiranya Bapak mengabulkan permohonan kami
6. **Partikel (p); Cakapan (cak)**
   - untuk mendahului kalimat tanya
   - **Contoh:** -- besok ada ulangan? -- tamu itu pamanmu?
7. **Partikel (p); Cakapan (cak)**
   - atau
   - **Contoh:** mau minum teh -- kopi
   - **Contoh:** jadi berangkat hari ini -- besok

- bermain air basah, bermain api letup, bermain pisau luka
- bersuluh menjemput api
- hitam, hitam kereta api, putihputih kapur sirih
- jauh panggang dari api
- kalau tak ada api, masakan ada asap

- meletakkan api di bubungan
- mengusir asap, meninggalkan api
- seperti api dalam sekam
- seperti api makan (di dalam) sekam
- seperti kelekatu masuk api
- seperti rabuk dengan api

- kecil cabai rawit (lada api)
