# Kamus Besar Bahasa Indonesia — K (Bagian 009)

> Rentang kunci: `kereta api` sampai `kesyahduan`.

> Definisi dipertahankan; hanya struktur, duplikasi identik, dan karakter tersembunyi yang dibersihkan.

---

## kereta api

**Pemenggalan:** ke.re.ta api
**Pelafalan:** /kêreta api/

### Makna
1. **Nomina (n)**
   - kereta yang terdiri atas rangkaian gerbong (kereta) yang ditarik oleh lokomotif, dijalankan dengan tenaga uap (atau listrik), berjalan di atas rel (rentangan baja dan sebagainya), digunakan untuk kendaraan umum

### Kata turunan
berkereta api; perkeretaapian

### Gabungan kata
- kereta api bawah tanah
- kereta api bumel
- kereta api diesel
- kereta api ekspres
- kereta api listrik
- kereta api magnet
- kereta api uap

**Sumber:** [KBBI Daring](https://kbbi.kemdikbud.go.id/entri/kereta%20api)
